Let \(\mu _G : \mathrm{Measure}\, G\) denote the unique left-invariant regular Borel probability measure on \(G\). Concretely: take Mathlib’s MeasureTheory.Measure.haarMeasure (with any compact set of positive measure as the normalization parameter) and rescale by \(1 / \mu (G)\) via haarScalarFactor so that \(\mu _G(G) = 1\).
