11.3 The isotypic Hilbert sum

Theorem 87 Matrix coefficients of \(\rho _\xi \) live in \(L^2(G)_\xi \)
#

Lean declarations

  • UnitaryRep.matrixCoeff_mem_isotypicComponent

For each \(\xi \in \widehat G\) and \(u, v \in V_\xi \), the matrix coefficient \(\pi _{u, v}^{\rho _\xi } \in L^2(G)\) lies in \(L^2(G)_\xi \).

Proof ▶

The closure of the right-translates of \(\pi _{u,v}^{\rho _\xi }\) (under \(\rho ^R\)) gives a closed \(\rho ^R\)-invariant subspace \(W \leq L^2(G)\). The map \(V_\xi \to L^2(G)\), \(u' \mapsto \pi _{u', v}^{\rho _\xi }\), is a \(G\)-equivariant linear map (right-translation action on \(L^2(G)\) matches the \(\rho _\xi \)-action on \(V_\xi \) via the matrix-coefficient identity); it has trivial kernel (Schur, since \(V_\xi \) irreducible and the map non-zero), and image is \(W\). Hence \(\rho ^R|_W \cong \rho _\xi \), so \(W \subseteq L^2(G)_\xi \), hence \(\pi _{u, v}^{\rho _\xi } \in W \subseteq L^2(G)_\xi \).

Lean declarations

  • PeterWeyl.isotypicComponents_topologicalClosure_eq_top

\(\overline{\sum _{\xi \in \widehat G} L^2(G)_\xi } = L^2(G)\).

Proof ▶

By Theorem 87, every matrix coefficient lies in some \(L^2(G)_\xi \). Hence \(\mathcal A \subseteq \sum _\xi L^2(G)_\xi \). By Corollary 80, \(\mathcal A\) is dense in \(L^2(G)\), so the closed sum is all of \(L^2(G)\).
